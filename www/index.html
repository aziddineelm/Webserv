How It Works

            
Tips for the DELETE method

          

        

        

          The DELETE method removes the resource at the given URL.
          Try uploading a file in the POST section, then delete it by entering its path (e.g. /uploads/myfile.txt).
          You can also delete files directly from the Media Gallery.

CGI Scripts

            
Test the available CGI scripts on this server

          

        


        


          
          

            
hello.py

            
Simple hello world script — returns a greeting message via GET.

            
          


          
          

            
echo.py

            
Echoes back the request body sent via POST.

            

              
            

            
          


          
          

            
post_echo.py

            
Echoes POST body with Content-Length header.

            

              
            

            
          


          
          

            
status.py

            
Returns a 404 status — useful for testing error handling.

            
          


          
          

            
timeout_test.py

            
A script that intentionally never finishes — useful for testing timeout handling.

            
          


          
          

            
session.py

            
Tests session handling by maintaining a counter across requests.

            
          


          
          

            
info.php

            
Outputs PHP configuration details and phpinfo().

            
          


          
          

            
time.php

            
Returns the current server time and date in JSON format.

            
          


          
          

            
env.php

            
Returns the CGI environment variables received by the server.
